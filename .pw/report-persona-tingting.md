# 第三人称改造 · 玩家需求清单（婷婷 / 24 岁 / 手机竖屏党）

> 先摆清我的条件：只用手机玩，安卓微信内置浏览器为主，偶尔 iPhone；九成时间躺床上竖屏，横屏嫌麻烦但也用过。玩过《骗子酒馆》手游版。我对画面的底线三条：**别挡我要点的东西、别让我找不到谁在说话、别在我要用的时候消失。**
>
> 佐证截图：`.pw/shots/3p-base-*.png`（基线四张）+ `.pw/shots/tt-*.png`（我视角补跑：390×844 竖屏、844×390 真横屏 landui，脚本 `.pw/probe-tingting-mobile.cjs` / `.pw/probe-tingting-land.cjs`，端口 8833/8834）。文中尺寸全部来自页面真实测量（getBoundingClientRect），不是目测。

## 1.【痛点】现在的画面，我躺床上玩会骂人的地方

1. 【必须】**揭晓那一刻，人和牌桌整个消失**（3p-base-desktop-revealed.png）：黑色虚空里飘一张题卡，像闪退切到了 PPT。真心话大冒险最好看的恰恰是揭晓后那几十秒——谁抽到题、谁脸红、谁装淡定，现在全没了。（我手机上反而没消失，见第 3 节——同一条规则在不同设备上表现不一致，本身就是问题。）
2. 【必须】**屏幕下沿挤爆，工具栏在屏幕外**（tt-mobile-myturn-choosing.png，390×844 实测）：顶部标题+状态条占到 y=162；座次环 162–497；「选择一项」按钮 545–713；省电 toast 714–820；底部工具栏 791–923——**超出屏幕 79px**。我不滚动就点不到「退出房间」那排，点之前还得先划走盖在工具栏上的 toast。
3. 【必须】**toast 盖按钮**（3p-base-mobile-choosing.png）：「检测到这台手机跑不满动画…」正好压在工具栏上，两侧只露出「连麦」「战况」半个钮。弹窗可以存在，但不能长在我要按的地方。
4. 【必须】**揭晓后我要按的按钮在屏幕外**（tt-mobile-revealed.png 实测）：题面卡 521–919（下缘越界 75px），「完成啦 / 免答牌」贴着屏幕底边裁掉一半，工具栏 939–1058 整排在屏外。轮到我答题，我要的是按钮，不是滚动条。
5. 【必须】**「轮到谁了」看不清**（3p-base-mobile-choosing.png / tt-mobile-myturn-choosing.png）：顶部那行「轮到你了！」是暗紫红字压暗紫底，手机离脸 40 厘米躺着看等于没有。
6. 【必须】**顶部状态条被左右裁切**（同上两张图）：「第6手 / 轮流 / … / 跳过0」在 390 宽下两端都被切掉一半，数字读不全。
7. 【必须】**两个人叠成一个人**（3p-base-desktop-choosing.png 左侧）：两个头像上下叠死，名牌只显示一个「小雨」，六个人我只数得出五个。谁被挡住谁就等于没来，点名、押注我都不会想到 TA。
8. 【必须】**我看得见自己的正脸**（3p-base-mobile-choosing.png 中央）：号称我坐在桌前，我的卡却跟别人一样是正面头像，还带名牌+「当前」章，占着座次环正中最贵的一块地。第一人称却看见自己的脸，出戏。
9. 【加分】**桌面读作「紫墙」不是桌面**（各 choosing/drawing 图）：毡面竖在大家身后，牌堆是躲在头像后面的半透明幽灵卡。我完全没意识到「桌上有一叠牌可以抽」。《骗子酒馆》里牌堆是真实躺在台面上的一叠，一眼就知道牌从哪来。
10. 【必须】**抽卡走路在手机上看不懂**（tt-mobile-drawing-me.png）：我起身去抽卡，实际观感是「我的头往上飘了一截，名字和『当前』章留在原地」——头和名字分家，没有脚，也不知道要走多久、走到了没。
11. 【必须】**有的玩家身体变成一块大三色转盘**（tt-mobile-myturn-choosing / tt-mobile-drawing-me / tt-mobile-revealed 连续三张里，阿凯/婷婷/大飞三人都是这样）：头像外的花色转盘整个露出来，人只剩个小脑袋，从选卡到揭晓一直不消失。不管这是什么功能，我看到的就是「人被转盘吃了」，而且分不清它是状态、标记还是坏了。
12. 【加分】**横屏 landui 缺斤少两**（tt-land-myturn-choosing.png / tt-land-revealed.png）：左桌右操作的思路是对的，但标题被状态条压住、右下「退出房…」裁一半、揭晓时工具栏实测 390–422（**超出 390 屏高 32px**）、左缘 -17 被裁。我本来就懒得转横屏，转过来还缺这缺那，就更不想转了。

## 2.【第三人称期待】「我的背影 + 牌桌 + 对面玩家」的硬标准

- H1【必须】**一眼认出背影是我，且它是活的**：背影要带我的特征（发色/衣服主色跟我头像一致），并且会动——我说话它晃，我起身它走，被点名它有反应。一张静立的后脑勺贴图不算第三人称。
- H2【必须】**背影不挡人**：背影头顶不得高过对面最近玩家的下巴线；对面所有人从脸到名牌必须完整落在背影轮廓之外。390 宽手机、844 宽平板、桌面端，条条都要成立。
- H3【必须】**牌桌要「躺得下」**：牌堆和翻开的牌要看着是放在一块台面上的；竖屏不滚动、不凑近就能读清牌面正文（字号不低于现在题面卡正文）。「紫墙 + 幽灵牌堆」不合格。
- H4【必须】**我的操作永远可点**：选卡、完成/跳过、免答牌、押注、退出，任何按钮不许被背影、toast、名牌或别人头像压住；按钮压在背影身上时，按下去必须是按钮；toast 一律不进屏幕下沿 40% 区域。
- H5【必须】**轮到我用「场景内」的方式告诉我**：背影前倾/举手 + 镜头轻推都行，但牌桌和对面玩家全程留在画面里，不许切黑、不许只弹横幅。转场结束后我靠「背影的姿态」就该想起来轮到我了，不用读小字。
- H6【必须】**说话的人半秒可辨**：谁开麦说话，TA 的头像/身体有明显光效 + 名字变色 + 可见话泡，并且从我的座位看 TA 不被任何人（包括我的背影）遮挡。

## 3.【阶段连续性】每个阶段画面里必须始终有什么

- 选卡【必须】：牌桌、全部玩家、我的背影、当前玩家高亮，四样全在。此刻我最需要看清对面每张脸，因为接下来要围观、押注的就是 TA。
- 抽卡【必须】：起身的环节要在我眼前完成——人从座位走到牌堆、手伸向牌堆、抽牌停顿一下再回座，名字**跟着人走**，牌堆全程可见。我希望的运镜：我的回合就贴着我背影走（镜头跟半步），别人的回合就原地看 TA 走，两边都不要切黑场。现在「头飘一段 + 徽章 + 名字留在原地」不行。
- 揭晓【必须】：最关键的阶段，人**只许多不许少**。答题人的脸、主持、围观群众都要在；题面以「桌上翻开的牌」存在，不许独占全屏，更不许把桌子撤了。现状实锤：桌面端短窗（宽>601 且高≤920，见 index.html:878 所在媒体查询）整桌消失，手机竖屏反而因为宽度不到 601 逃过一劫——正确标准应该统一成我手机上这样：**缩小让位，但不许消失**。
- 交接【必须】：上一题结算到下一轮之间桌子不空场：分数变化在人身上飘出来（现在 +10 有，保留），新持麦人高亮 1 秒内能找到；谁都不许在下次行动前凭空消失或跟别人叠上。

## 4.【座位可读性】6–10 人时

- 【必须】**零重叠是底线**：任何两个玩家的轮廓不许互相压住头部（现在 ±60°/±120° 两组座位几乎重合那种必须消失）。退一步，衣肩允许碰，**脸 + 名牌必须完整**。
- 【必须】**我的最小可接受尺寸**（直觉值）：手机竖屏 390 宽，头像脸部可用直径 ≥ 40px、名牌字号 ≥ 11px；桌面 1440 宽 ≥ 64px。再小我就认不出人只能靠数位置——数位置是干活，不是玩游戏。
- 【必须】**相邻可见间距 ≥ 6px**（桌面 ≥ 12px）：两个头贴死我就分人，只能靠名牌一个个对。
- 【必须】**8–10 人允许分层**（后排高一档、往斜后退），但下层头顶不许切进上层下巴；分层结果要稳定，不能每回合重排——我要建立「阿豪坐左后」的空间记忆。
- 【加分】**点任何被挡或太小的人，弹出 1 秒大图**（脸+名牌+状态），松手消失。10 人局里这功能对我是刚需级加分。

## 5.【手机】背影占屏的容忍上限（空间争夺战）

参照系先说清：《骗子酒馆》手游竖屏里，我的背影+手牌带占屏幕下沿约四分之一到三分之一，头顶大致压在屏幕下三分之一线附近，对面玩家和桌面完整在它上方——「有存在感但不烦人」就是这个比例。落到这游戏：

**竖屏 390×844（躺床主场景）**
- 【必须】背影（头+肩+一点背）整体高度 ≤ 屏高 22%（约 185px），宽度 ≤ 屏宽 45%（约 175px），居中或微偏一侧均可；
- 【必须】背影只许出现在 y ≥ 640 的区间（题面卡/按钮之下），且**不拦截触摸**——按钮叠在它身上时必须是按钮接到点击；
- 【必须】竖屏内容总高现在已经 923px（超屏 79px），背影的空间必须从「座次环下半段 + 我的正面卡」那约 335px 里省出来，不许再往底部加高；
- 【必须】iPhone 底部 home 条 + 微信工具栏实际吃掉约 70–90px，「完成啦」这类必点按钮的底线不得超过 y ≈ 760。

**横屏 844×390（landui）**
- 【必须】背影高度 ≤ 屏高 30%（约 117px），放桌面下沿中央，头顶不盖对面玩家名牌；左桌右操作分栏保留，背影不许侵入右栏；
- 【必须】先修横屏揭晓工具栏越界（390–422，越界 32px、左缘 -17 裁切），再谈加背影。

**通用**
- 【必须】任何 toast/引导浮层不进「操作带」（竖屏 y 545–780、横屏右栏），要出就出在顶部状态条下方，并且自动让开状态条。

## 6.【加分项】只能再加一个「骗子酒馆味」的细节

我选：**轮到我时，我的背影前倾 + 举手，镜头向桌心轻轻推半格，桌面和对面玩家全程留在画面里。**

理由：这一个动作同时治好我抱怨最多的三件事——「该我了」不用再读顶部那行看不清的小字（痛点 5）；背影从装饰变成「我在场」的证据（硬标准 H1、H5）；推近的幅度只要守住「题面和对面名牌都还看得清」，就是《骗子酒馆》那种「镜头替我坐直了」的手感。至于被点名时镜头怼到我脸上的戏剧化运镜，我不反对，但那是炸场用的彩蛋，替代不了每回合这一个标准动作。
