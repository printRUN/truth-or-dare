# 第三人称改造 · 玩家模拟简报（供 persona agent 使用）

## 任务背景
项目 D:\myidea\truth-or-dare（单文件 index.html，~5772 行，纯 CSS 3D 无 WebGL）是多人「真心话大冒险」游戏。
当前分支 feat/3d-one-take 已实现：牌桌=第一人称视角（你坐在桌前，自己的头像卡在屏幕下方最近处，其余人围椭圆环）。
**用户目标：改成第三人称视角游玩，借鉴《骗子酒馆》(Liar's Bar)**——即你能在屏幕下方看到「自己的角色背影」（后脑勺+肩膀，位于镜头与牌桌之间），对面是围桌的其他玩家，中间是一张真正的牌桌。

## 骗子酒馆的画面要素（参照）
1. 镜头在「我的角色」身后上方，越过肩头看桌面（over-the-shoulder）。
2. 屏幕下沿中央是我的角色背影（占比明显，近大远小中「最大」）。
3. 桌面是一块真实 readable 的台面：牌堆/已打出的牌躺在上面。
4. 其他玩家坐对面与两侧，脸朝向我（可见全身/半身）。
5. 轮到我行动时镜头/角色有反馈（起身、推向桌心等），但桌面与人始终在场景里。

## 当前实现的关键事实（已核实）
- 摄影机 = `#world3d` 的 transform，JS `Cam` 调度（SPEC.md「一镜到底」节）。game 常态机位 `Cam.base.game = {x:0,y:0,z:-24,rx:8}`（微微俯视）。
- 座次 = `layoutRing()`（index.html ~3778 行）：我把我的卡放椭圆环正前方（--rx 50% / --ry 76% / --rs 1.21），其余人按角度摊开。
- 我的卡与别人一样是「正面头像+身体+名牌」——**没有背影**。
- 桌面毡面 = `.players-grid.ring3d::before` 画的椭圆渐变，位于座次环平面内（竖直平面，非真正躺下的桌面）；另有一个 rotateX(74°) 的 `.table3d` 光池垫底。
- 牌堆 `.table-deck` 常驻桌心（rotateX 16° + scale 0.72）。
- **已发现的现有问题**：
  a) 桌面 1440×900、6 人时，±60°/±120° 两组座位 x 几乎重合 → 阿豪/大飞被小雨/圆圆遮挡（基线截图可见）。
  b) `index.html:878`：`body:not(.landui) #screen-game:has(#card-section:not([hidden])) .players-grid.ring3d { display:none }` —— 揭晓阶段整个座次环（连同桌面）从场景里消失，桌面端也一样中招（该规则本意只救窄屏）。
  c) 毡面在竖直平面里，第一人称俯角 rx=8° 下读作「身后一面紫墙」而不是「面前的桌面」。

## 工程红线（SPEC.md 第 2 节，方案不能违反）
- `.world` 绝不开 preserve-3d（3D 命中测试会让全站点不动，test-3d.cjs 回归锁）。
- `#app` 的 perspective 使其成为 fixed 后代包含块：toast/浮层必须挂 body。
- 新动画必须给 REDUCED（prefers-reduced-motion）和 body.loperf 补静态退路。
- 牌堆/桌面锚定只能用 offsetLeft/offsetTop（rect 在运镜中会被投影扭曲）。
- 飞角色动画 flyAvatarToDeck 依赖我卡上的头像+名牌元素可测量。
