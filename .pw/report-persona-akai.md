# 第三人称改造 · 玩家需求清单（persona：阿凯）

**我是谁**：阿凯，28 岁，周五局的组织者。桌游+电子派对游戏老玩家，《骗子酒馆》几十小时。今晚我主持，我的真实用法是：笔记本 Chrome（1440×900）**投屏到电视**——那台既是我的操作台，也是全屋人共看的舞台；朋友们各自手机入房。所以我盯画面有两重身份：**坐在桌前的玩家**，和**替全桌看屏幕的主持**。挑剔但讲道理：我要的是「第三人称的骗子酒馆味」，不是炫技。

## 一、【痛点】现在的第一人称画面，哪里让我出戏

1. 【必须】**揭晓那一刻，桌子和人全没了**。（3p-base-desktop-revealed.png / 3p-akai-9p-desktop-revealed.png）牌一亮，9 个人、桌子、毡面整体消失，只剩一张孤卡和一个鬼影椭圆，牌堆悬在半空。真心话大冒险的高潮是「全桌人盯着圆圆看她念题」——结果电视上那一秒是一张问卷。押注面板写着「TA 会完成这张牌吗」，可「TA」已经不在画面里了，我押的不是一个人，是一个名字。
2. 【必须】**画面里没有「我」**。（3p-base-desktop-choosing.png）我的卡和别人的卡长得一模一样——正面头像+名牌，只是大一号、多了个「你」字。骗子酒馆里我低头能看见自己的手、胸口的牌、后脑勺压住画面下沿；这里我找不到任何「我坐在这」的锚点。真心话/大冒险两个按钮浮在桌沿外的地毯上，读作「系统替我按」，而不是「我伸手拍桌选的」。
3. 【必须】**桌面不是桌面**。（choosing/drawing 两张桌面图）那块紫色毡面在透视里读作「我身后的一面紫墙」，牌堆浮在「墙」的半空（位置比对面的婷婷的脑袋还高）。骗子酒馆的牌是**拍在桌面上**的，有台面承载感；这里的牌像贴在背景板上的贴纸。
4. 【必须】**6 人就已经叠座**。（3p-base-desktop-choosing.png 左侧）两个头像叠成「双头怪」，阿豪/大飞基本被小雨/圆圆盖住，只露出多余的头顶。9 人局更糟（3p-akai-9p-desktop-choosing.png）：婷婷/阿豪、老白/阿珍两对完全贴脸，远座大飞/圆圆卡宽只剩 52px，名牌字小到投屏后 2 米外不可辨。我在电视前根本无法一眼说清「桌边坐着谁、现在到谁」。
5. 【加分】**状态语言混乱**。（3p-base-desktop-drawing.png）圆圆去抽卡，画面表现是：她脸上盖了一个转圈扇形（像视频加载圈）+ 人变暗。事后我读 SPEC 才知道设计意图是「离座去卡堆」——但画面完全读不出「人走了、走到桌心」，读成「她那边卡了」。另外抽卡阶段底部工具条整排上浮到屏幕中间、压在桌沿上，读作「换了一页」，不是「同一张桌子的下一拍」。
6. 【加分】**顶部战况条存在感过低**。（choosing 两张）「第 X 手 / 轮流 / 跳过」那排 HUD 在选卡阶段几乎隐形（淡到和标题糊在一起），揭晓阶段反而清晰。主持要报分，我要的是抬头随时能念的数字，不是藏猫猫。
7. 【必须】**手机端我的卡被切出屏**。（3p-base-mobile-choosing.png）竖屏里「我」卡在屏幕左缘只剩半张，主持人徽章被裁掉一半；（3p-base-mobile-revealed.png）省电模式的 toast 常驻盖在底部动作区上，按钮点起来心里发毛。横屏 landui 9 人全挤在左半屏相互叠压（3p-akai-landui-choosing.png），标题还被毡面穿帮盖住一角。

## 二、【第三人称期待】「我的背影+牌桌+对面玩家」的硬标准

1. 【必须】**屏幕下沿中央有「我的背影」**：后脑勺+肩部剪影，位于镜头与牌桌之间，是全画面里「最近、最大」的一个角色。任何阶段不许消失。第一眼它要回答的问题只有一个：「我坐在这。」
2. 【必须】**背影必须能看出「是我在动」**，可验证的表述：我在现实里做的每个操作，背影要有对应动作——我选真心话时背影伸手/前倾拍桌；我抽卡时背影起身（或探身）伸向桌心牌堆；轮到我时背影有坐直/推桌的姿态变化。不能「镜头在动、人是一张静态贴图」。
3. 【必须】**我说话时背影要有反应**：连麦开麦说话，背影要有呼吸/头部微动/身体摆动（骗子酒馆的角色 idle 和说话摆动是我认这个味的关键）。声波绿环如果还做，请长在「我的背影」身上，而不是一个悬空头像圈上——背影是我在桌边的化身，不是我的一张证件照。
4. 【必须】**中间是一块真正 readable 的台面**：牌堆和打出的牌「躺在」台面上——能一眼看出上下层关系（牌在台面之上、台面在对面玩家之前、在我背影之后）。现在「牌浮在墙前」的关系必须消失。
5. 【必须】**对面与两侧玩家可见、脸朝向我、互不遮挡**：每个玩家的脸和名牌完整可辨。第一人称时代的叠座问题不允许换个镜头跟着搬过来——镜头后退了，人还叠着，那这次改造就白做。
6. 【必须】**轮到我行动时有反馈，但场景不切走**：可以过肩推近、可以背影前倾，但「我的背影+桌面+对面玩家」三者同框是底线。整屏换成一张卡、全桌人蒸发，一律打回。

## 三、【阶段连续性】每个阶段的画框里应该始终有什么

总原则：**换的是桌上的戏，不是房间**。从选卡到交接，桌子、我的背影、对面的人应该一直在，变的只是桌上那张牌和人的姿态。

1. 【必须】**选卡**：我的背影（下沿）+ 台面 + 桌心牌堆 + 全体对面玩家 + 真心话/大冒险选项。选项要读作「摆在我面前的桌沿上」，和我的背影有从属关系，不是浮在半空的两张 UI 卡。
2. 【必须】**抽卡**：抽卡者「从座位走到桌心」的过程要在画面里——人离座、移动、到牌堆前，其余人留在座位围观。现在是脸上一个加载圈（见痛点 5），人根本没动。洗牌动作要发生在台面上。
3. 【必须】**揭晓**：全员留场。这一拍最不能断——题面卡可以放大到桌心上方成为焦点，其他区域允许压暗让焦点，但桌子、我的背影、对面所有人必须还在画框里。「大家围桌看题」的画面成立，这个游戏才成立。押注面板浮在下方没问题，但它替代不了「人在场」。
4. 【必须】**交接/下一轮**：镜头回桌心或滑向下一位持麦人，人始终坐在座位上。（3p-base-desktop-next.png 显示选卡区回来时桌子还在——这个方向是对的；但按钮直接压在桌沿和名牌上，画面分层要理顺。）
5. 【加分】**随机点名/命运转盘**这类全场扫视的瞬间，扫的应该是「桌边的人」——前提还是那句话：环上每个人都得能被扫到、可辨认。

## 四、【座位可读性】6–10 人时每个对面玩家都可辨认

1. 【必须】**零叠压是底线**：任意两张玩家卡的名牌不重叠、头像边缘不相交。现状是 6 人时 ±60°/±120° 座位 x 几乎重合（基线左侧双头怪），9 人时侧座两对中心距 ~64px、卡宽 56–63px，贴死。第三人称重排时这条作为验收红线，不是美观建议。
2. 【必须】**远座最小尺寸直觉**：以我的 1440×900 投屏为基准，最远座卡宽 ≥70px、名牌字 ≥12px 当量，投到电视上 2 米外能认出「这是谁」。9 人局实测远座 52px——不达标。做不到就分两排阶梯错位（前后排 x 错开），别把 10 个人硬挤在一圈。
3. 【必须】**间距直觉**：相邻两卡中心距 ≥ 卡宽的 1.2 倍。低于这个数，在电视上读作「两个人挤一个座位」。
4. 【加分】人数多时我接受「侧座适当缩小 + 非当前回合整体稍暗」的取舍，但三个目标必须一眼锁定：当前持麦人、被点名者、押注对象——高亮强度以电视 2 米外可辨为准。

## 五、【手机】背影占屏比例的容忍上限

1. 【必须】**竖屏 390×844**：底部选卡双按钮、题面文字、完成/跳过按钮，任何时刻不能被背影或任何常驻元素遮挡。现在省电 toast 常驻盖按钮区已经是硬伤，别再让背影雪上加霜。
2. 【必须】**「我」不能出屏**：竖屏现在我的卡被左缘切半、徽章被裁（3p-base-mobile-choosing.png）。第三人称下如果背影在小屏放不下，宁可缩到只露头顶+肩线，也不许挤占操作区或被裁切。
3. 【必须】**横屏 landui**：我的容忍上限直觉——座次区（左半屏）里我的背影高度 ≤ 座次区高度的 40%，右半屏题面与操作完整可用。现在 9 人已经相互叠压（3p-akai-landui-choosing.png），背影再大就是灾难。揭晓时横屏保留了围桌画面（这点比桌面端做法对，保持），但押注条压住卡片下缘要理顺。
4. 【必须】**桌面端不许跟着手机缩**：手机可以轻量（见下），但我投屏的 1440×900 上背影必须全程在画。
5. 【加分】手机允许「背影只在轮到我时进画」的省电轻量档（低配机自动降），桌面投屏端不享受这个豁免。

---

## 六、【加分项】只能再加一个「骗子酒馆味」细节

**我选：轮到我时，我的背影做「前倾推桌/起身」动作帧，同时镜头微微过肩推向桌心。**

理由：骗子酒馆里「该我了」这个信息，一半来自角色姿态而不是 UI——我抬头瞟一眼电视就知道下一轮是不是我，不用掏手机看。作为主持，这个动作就是全桌的发令枪：背影一动，大家的视线自然交回桌面。它一个细节同时解决两个问题——「背影是死的贴图」（期待 2）和「轮到我读不出」。次选是「被随机点名时镜头推到我面前两秒」，社死感拉满，但覆盖的场面太窄，不值一个独占名额。

---

**验收方式我先放这**：改完我会在 1440×900（投屏）、390×844 竖屏、844×390 横屏三档各把选卡/抽卡/揭晓/交接过一遍——任何一拍「桌子或人从画面里消失」，直接打回。
