## 走查方法论的教训

1. **帧序列分析比截图走查值钱**：刚体是否成立、「转场可可见段只有 350ms」这类结论只有逐帧采样能给。
2. **中段帧必须冻结后截**（`getAnimations().pause()`）：按角度 waitForFunction 返回后再写盘，
   200-400ms 延迟足以让 640-800ms 转场走完，会拍到「假绿」的中段。
3. **agent 并发上限 ~2**：第 3 个并发 agent 会以 user concurrency limit exceeded 秒挂，重跑即可。
4. **玩家 agent 可能中途死**（模型请求失败）：让截图先落盘、报告后写——这次手机 agent 死了但 22 张
   证据全在，主 agent 直接读图补完了报告。
