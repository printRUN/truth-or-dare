走查方式：本地链路真开局（UNO 4 page 同 context `net=1&localnet=1`；tod 本地房间 4 page），4 张**发型差异极大**的 2D 头像，逐座位 3D 头投影近截 + 提取器落点取证。未改任何游戏代码。

## 结论（先行）

**用户反馈完全成立，且瓶颈比「3D 发型种类少」更靠上游：特征提取器把 4 张截然不同的 2D 发型全数压成了 `short×3 + bald×1`，3D 侧共享 builder 的 long/bun/afro 几何一次都没被触发。** 玩家在真机视角下认不出自己的头像，4 个 3D 头是「同一颗蛋换衣服颜色」：

- **UNO 半身像**（南位俯视，头部仅 **33–55px** @1280×800）：4 个头像两两并排平均 **2/5** 分得清；单头认回 2D 原图平均 **1.25/5**。
- **tod 近景头**（r0.2，头部 80–145px）：更糟——3 个「同款波波头」+ 1 颗光头蛋，两两 **1.5/5**，单头 **1/5**。
- 出现两处**特征反转级 bug**（比「没表现」更糟的「表现错」）：personas 大卷发 → **bald**（卷卷直接变成光头蛋，连 2D 上的大墨镜也一并丢失）；adventurer 金色长发 → **金发被误判为肤色**（阿琅的 3D 头皮肤是发色、头发反而是深棕兜底色）。

## 二、「2D 有但 3D 完全没表现」特征清单 Top5（按出现频率）

1. **刺头/立发**（avataaars、adventurer 等池高频）— 3D 是光滑球盖（hairTop 0.31π 球冠），无任何尖刺几何。本次刺头哥直接牺牲。
2. **刘海/发际线造型**（齐刘海、锅盖头、中分…）— 发缘是固定球冠弧线，无刘海几何；big-smile/Sophia 类锅盖头与普通短发在 3D 无法区分。
3. **帽子/头饰**（avataaars 冬帽/头巾/花冠等）— 检测链路完全没有「帽子」概念；更糟的是**帽子像素会被当成头发**，把 3D 发帽染成帽色（网格中 avataaars/Sarah 白冬帽 → 会渲染成白色「短发」），特征被顶替而非丢失。
4. **马尾/双马尾/辫子**（personas/George 双马尾、adventurer/Prem 双马尾、Ariana 侧马尾）— 无束发几何；中高度侧发过不了 `lowMass`（y≥0.68h 且 |x−0.5|≥0.24w）的「真垂发」判据 → 塌缩成 short。
5. **卷发纹理/蓬松度** — afro 也只是 1.36× 光滑宽球（纹理全无）；personas 大卷更是整条提取链失败 → **bald 反转**（本次实锤）。附：**墨镜在 bald 路径整体丢失**（glasses 检测挂在有发分支之后），发色渐变/挑染压成单色。

## 三、UNO 南位俯视视角下，哪些特征最可读

头部仅 33–55px（对手位半身 69–93px、屏占 5–7%）：
- **可读**：有发/秃二值 > 发色色相（帽状色块） > （若检出）深色墨镜点、胡子颌壳。即**「颜色+有无」可读，「形状」不可读**。
- **不可读**：long 侧垂锁（两根细椭球，侧缘 sub-pixel 条）；bun 丸子（钉在**后顶** `(0, 0.98r, −0.30r)`，南位前视角被颅球遮挡，俯视角也只露一点弧）；afro 的 1.36× 加宽（41px 头上只多 ~12px）；刺头/刘海（根本没有几何）。
- tod 近景（80–145px）：波波头 vs 秃可辨，纹理仍不可读；**房主永远看自己后脑勺**，发量信息≈0。

## 四、可执行建议

1. **P0 修提取器两处反转**（都是「表现错」不是「没表现」）：
   a. `bald` 判定加像素硬门槛——顶带非肤质量 topMass>0.012N 时禁判秃（钉扎 `pinBald=false` 只在「组件不存在**且**像素也空」时才允许 bald）；
   b. 肤色候选若与顶带主簇同族（dist<0.07，即「肤」其实是头发）则剥夺肤色资格——治金发→肤误判。
2. **P1 补「剪影级」发型几何**（40px 也读得出的轮廓差）：刺头（帽缘 6–8 只小锥）、刘海（帽前缘下沿盒）、帽子（筒+檐独立帽色）。这三项覆盖失败频率 Top3。
3. **P1 bun 前移抬高**（+z / +y），让南位俯视能看到丸子弧；long 侧锁外倾加大成剪影级。
4. **P2 身份冗余**：把 2D 头像底色（配方 `b` 字段）同步到名牌描边/底座色环——头像剪影失败时仍可靠「色环认人」（现状底座=玩家序颜色，与头像无关）。
5. **P2 tod 房主背面**：long/afro 的 hairBack 后颅覆盖加厚，避免「自己的头=裸球」。
