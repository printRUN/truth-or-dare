### 最违和的 3 个（判定+参数级修正）

**① open-peeps/Leo：爆炸头→秃（P0-1，提取器 bug）**
根因（av3-feat.js:37-40）：背景采样四角全透明（open-peeps 无背景板）→ 退到边缘中点 `[2,h>>1] [w-3,h>>1] [w>>1,2]`——三个点全落在触边的黑色爆炸头上 → `opaque=3≥3` → **bgc=纯黑** → `isBg` 把 dist<0.16 的黑爆炸头、黑描边、黑衣轮廓整簇当背景剔除 → hairC 空 → open-peeps 不在 PIN_HAIR → `style='bald'`。任何「深色头发触边的无背景画风」都会中招。
修正：角样本不足 4 个时**禁止**退到边缘中点，直接 `bgc=null`（透明协议下 alpha<128 已足够）；或边中点样本只允许参与「与角样本同色」的确认。验收门禁：open-peeps/Leo → style='afro'、发色≈#1a1a1a；open-peeps/Mika（丸奶奶，白发不触边）→ bun。

**② micah/Maria（连同 Jack）：秃→绿盔+笑脸（P0-2/P0-3）**
根因（实跑证实）：`pinDiff('micah',seed,'hair',[])` 输出 SVG 字节确实变了（hair:true），但 micah 的 hair 池含「视觉上无发」的变体——**字符串差分≠像素差分**。verify 表记 micah「短发·眼镜」全对是循环论证：钉扎真值本身就是错的，「零假秃」结论失效。
修正（三层）：a) pinDiff 改**位图差分**（64² 光栅，>0.5% 像素变化才算存在），字符串比较只做快速预筛；b) 钉扎说「有发」但顶带非肤像素 <0.008N 时，一律降级为 bald（像素否决权）；c) hairGuess 兜底**废除玩家色调色板**（绿/紫亮色做头发=外星人），改固定自然深棕 `#4a382c`。验收门禁：micah/Jack、micah/Maria → bald+眼镜；发色兜底色恒为 #4a382c。
附带：micah/Jack 2D 有深色胡茬，pinFacial 与像素兜底（bn2>0.016N 对稀疏点画胡茬太苛）都没抓到——胡茬类阈值降为 0.009N 并接受「下颌带非肤非发暗像素」作为 stubble 信号。

**③ toon-head/Aiden：金发→橄榄兜帽+矩形脸窗（P0-3+P1 几何）**
三个叠加缺陷：a) hairGuess 兜底色（colorIdx=3 → 0xcbb04f 深化=橄榄色）替 2D 的浅金发；b) `hairBack` thetaLength **0.52π**（从 36° 盖到 129.6°，即盖到 y≈-0.66r 下颌以下）→ 任何案例的「短发」都读成包头兜帽；c) 兜帽下缘+胡子颌壳在脸上拼出矩形窗。
修正：a) 同 P0-3 兜底色；b) **short 发壳 thetaLength 0.52π→0.38π**（下缘收到耳垂 y≈-0.28r），long 保留 0.52π 但侧锁独立承担垂发；c) 胡子颌壳限正面窗（见 P1-4）。

## 二、特征优先级（Q2）——按各游戏真实相机距离分层

实测依据：monopoly 全景头高 ≈28px（r0.1、rig elev 42°、dist 7.2，report-B 实测 28px）；uno ≈45px（r0.16、rig elev 46°）；tod/bombcat r0.2 全景 ≈40–60px，且 **report-A 实测揭晓近景根本不拍脸**（题卡特写，持麦人头肩不在画面内）——brief §3「揭晓近景下特征清晰可见」的前提不成立，本轮设计的一切特征必须按「全景小头」验收。

| 特征 | monopoly 28px | uno 45px | tod/bc 40-60px | 裁决 |
|---|---|---|---|---|
| 肤色 | 色相可读 | 可读 | 可读 | **必要项 #1**（人脸第一识别特征，三个游戏全要） |
| 发色 | 可读 | 可读 | 可读 | **必要项 #2** |
| 发型轮廓 bald/short/long/afro | 剪影可读 | 可读 | 可读 | **必要项 #3**；bun 在 28px 上是 9px 凸包，勉强可读，保留 |
| 眼镜 | 深色 1-2px 点，读作「有框」 | 环≈9px 可读 | 可读 | **必要项 #4**（uno/tod 权重高，monopoly 白送） |
| 胡子 | 下颌暗带可读 | 可读 | 可读 | 保留——性别/年龄读点，实现便宜 |
| 衣服色 | 不做（锥身玩家色） | 肩部色块可读 | 全身可读 | uno 保留；tod/bombcat 身体色应迁移（见七-2） |
| 嘴型 smile/open/flat | 不可读 | 不可读 | 仅冻结探针可见 | **降级为 P3**：实现可留（已写完），但不得进验收门禁、不得为它加提取特例 |
| 眉=发色 | 不可读 | 勉强 | 可读 | 保留但要防消失（见六-2） |

资源含义： P0 全部投给 肤色/发色/发型轮廓 的**远读正确性**；眼镜/胡子次之；嘴型不再投入。

## 三、争议点裁决（Q3 + brief §6）

1. **monopoly 锥身保持玩家色：维持原案，正确。** 28px 棋子的游戏性识别靠座位色；衣服相似交给头+名牌 chip。附加一条硬约束：名牌 2D 头像 chip 是当前唯一 carry 真脸的地方（report-B），特征头上线的验收图必须把「3D 头 vs 名牌 chip」放同一帧对比，防止「名牌比 3D 头更像本人」的自相矛盾观感残留。
2. **uno 肩膀染衣服色（去饱和 ×0.85）：方向正确，补两个参数。** a) 饱和 ×0.85 之外加 **L 钳 [0.25, 0.72]**——纯白/纯黑衣服在紫色氛围光下要么发光要么消失；b) 衣服色与该座位玩家色 hue 距离 <0.05 时，衣服色向灰偏移 0.3（防止与座位识别系统串色）。
3. **emoji 贴片保留：同意设计者**——「不要贴图」的语境是 DiceBear 人脸的贴片扁平感，emoji 无几何对应物。但 bombcat 程序猫脸的**深色方底描边环必须同轮修掉**（report-A P1：贴片圆角方牌感），改 alpha 轮廓抠底。
4. **眼镜固定深灰 0x2a2a33：维持原案，正确**（提取框色会被瞳孔/描边污染）。但必须加「墨镜子型」——见六-1。
5. **嘴型：降级**（见二）；**衣服色：按游戏分层**（见二）。

## 四、bald 与 r 适配（Q4）

1. **「戴头灯的蛋」风险真实存在，但解药不是发色发茬壳。** uno 46° 俯角下秃顶球面被方向灯打出镜面高光点（skin roughness 0.55 太低），28-45px 上读作头灯/卤蛋。report-A 已证明「秃头被扣发色大发壳」是全轮最遭恨的特征反转——给 bald 扣 1.01r **发色**半球等于把反转缩小一号再犯。修正：
   - bald 一律 skull 材质 roughness 0.55→**0.75**（哑光，高光消失）——此项 monopoly 也做，零成本；
   - r≥0.16（uno/tod/bombcat）加**肤色调发茬壳**：`SphereGeometry(r*1.012, 20, 8, 0, 2π, 0, 0.34π)`，色=skin 色 L×0.82（同色相压暗，读作青茬阴影而不是头发）；monopoly r0.1 不做（28px 上不可读，纯浪费）。
2. **发型变体几何：已经是纯 r 比例参数，两档 r 天然成立，不需要「无级适配」工程。** 逐项核对：侧锁/丸子/afro 放大系数全部 ×r，缩放不变；提取器阈值全是 N 的分数，尺寸无关。真正随 r 分档的只有两处：上面的发茬壳（r≥0.16 才做）和眼镜（r0.1 时镜环 0.8px 不可读——接受，monopoly 眼镜本来就只求「深色点」）。注意 bun 在 r0.1 时 9px 凸包处于可读下限，丸子半径 0.32r→**0.36r** 补一刀。
3. 顺带纠正 brief §2 与原型的一处漂移：afro 放大 brief 写 ×1.22、原型是 ×1.24——**共享 avatar-features.js 单一来源必须落地**（见七-5），且 open-peeps/Leo 的爆炸头 2D 宽≈头宽 1.6 倍，afro 系数 ×1.24→**×1.36**。

## 五、肤色与眼睛参数（Q5）

1. **饱和钳 0.55 不是「太艳/太灰」的二选一问题，是分层缺失 + 灯光预算失控。** 原型两灯（ambient 0.55 + directional 0.9）总量 >1.0，前脸辐照 ≈1.27×反照率，浅肤被漂成粉白（Zoe/miniavs），信道削顶又把中间肤推向橙（Ivy、big-smile）；而上线后还有 ACES+紫氛围光的反向漂白（report-B P0）。修正：
   - 原型/页面灯光预算：ambient 0.45 + directional 0.62，总量 ≤1.07；
   - 肤色饱和钳改分层：`L≥0.72 的浅肤 S≤0.42；中肤 S≤0.55；L<0.45 的深肤 S≤0.60 且 L 下限 0.25→0.30`（0.30 防紫光把深肤压成泥）；
   - 新增验收探针：渲染后回读脸颊像素，要求 hue 与提取肤色差 ≤0.04 且 |ΔL|≤0.12（页面级，ACES 环境下跑，不许只在原型中性光里绿）。
2. **眼白 0xf6f3ea 在深肤上对比度没问题**（micah 两例深肤上眼睛反而最清楚）——**眼睛的病是尺寸不是对比度**。现状 eye r0.17 + 瞳孔 r0.095（虹膜占比 56%）+ 瞳孔前端 z≈1.01r 比眼白球面(0.97r)凸出 0.04r，46° 俯角下就是 report-B 说的「浮在脸上的两颗珠子」。修正（P1-2 给出全参数）。
3. 红发系崩溃（dylan/Leo）：肤色色相卫兵只拒 0.22–0.86（绿青蓝紫），红橙 hh<0.02 且 S>0.55 的头发色直接通过肤色门。修正：肤色候选追加「`S>0.55` 一票否决」。

## 六、眼镜与眉毛（Q6）

1. **固定深灰框：对；但「墨镜/眼罩」必须分子型。** personas/Zoe 墨镜、big-smile/Aiden 眼罩都被判成普通眼镜，3D 反而渲染出 2D 看不见的眼睛。修正：eyeBand 检出像素的均值 L<0.25 → `glasses:'dark'` → 3D 渲染**深色镜片圆盘**（`CircleGeometry(r*0.24)`，色 0x1a1a22，粗框）并**不生成眼球**；普通框才走 torus+眼球。
2. **眉=发色对白发/浅发会消失：会，且一案已中**（adventurer/Kim 橙眉没入橙发壳；丸奶奶白眉在奶油肤上不可见）。修正：眉色 = 发色 L 钳 **[0.16, 0.62]**（超界向 0x3a332e 混 50%）；髭条同规则（白胡子奶奶的髭在浅肤上要有灰度读数）。
3. 眼镜几何本身有穿模：rim torus 圆心 z=0.80r 与眼球同心，环体半埋进球体，渲染上呈「浮在眼上方的弧」。修正随 P1-2。

## 七、其他挑刺（自由发挥，按视觉显著度排序）

1. **金鱼眼（全场 15/15 中招，最系统性的一处）**：eye r0.17、瞳占比 56%、瞳孔浮凸，把每个 2D 都改成同款瞪眼——这是「相似」的反面。P1-2 全套参数。
2. **tod/bombcat 的「头随身体朝桌心、无 billboard 需求」要打回**（brief §3）：report-A 实测机位在南、6 人局只有对面 1–2 人有正脸，其余看 3/4 背影——几何脸的五官在 55° 侧后可读面积趋零，只有肤色/发色/剪影存活。monopoly 已有 yaw-only billboard 先例（syncPawnFacesFrame，且与倒地系统解耦）。修正：tod/bombcat 特征头加 **head-only yaw 朝相机钳制 ±75°**（超界回桌心朝向），否则特征几何在这些页面的实际收益砍半。
3. **发壳色过深**：hair clampL 上限 0.50 把粉发/金发压成梅红/橄榄（Ivy 的粉→覆盆子，Zoe 的粉→正红）。修正：发色 L 钳 **[0.10, 0.68]**，S≤0.60。
4. **兜帽化+矩形脸窗**（toon-head/avataaars/micah 全中）：发壳下缘 0.52π 到下颌以下 + 胡子颌壳 thetaStart 0.52π 从嘴高起步且 phi 覆盖 331°（连后脑勺都包）——两壳一拼，脸只剩矩形窗。P1-3/P1-4 参数。
5. **brief 与原型已经出现参数漂移**（afro ×1.22 vs ×1.24）：设计者自己主张的共享 avatar-features.js 是对的，必须落地，四页内联必漂移；check-syntax 按 dicebear-local 先例做 sha 锁。
6. **嘴色在深肤上不可见**（adventurer/Kim 微笑弧消失）：mouth 色按肤 L 分档，L<0.42 → 0x3d1d18。
7. **张嘴大笑没有牙**（big-smile 的招牌白牙→黑洞）：`mouth='open'` 且嘴簇宽 >0.12w 时加白牙条（0.20×0.05r，0xf5f2ea）。
8. **性能账本不实**：brief 说「钉扎最多 3 次 SVG 再生」，avataaars 具名镜框 `names.some(pinDiff)` 最坏 8 变体 ×2 次生成 = **16 次**，加 P0-2 改位图差分后是 16 次 64² 光栅 ≈50ms。异步 onload 里可接受，但文档按最坏情况写，并对 avataaars 先做字符串预筛（同字节跳过光栅）。
9. **原型相机（0.25, 0.55, 2.6 平视 38°）与两页真实机位（42°/46° 俯角、dist 7.2）完全不同**——原型是「证件照机位」，验收结论对玩法机位没有代表性。修正：headproto 复跑时加一列 **46° 俯角 + 头高 28px/45px 的等效缩放渲染**，门禁以该列为准。
10. **ev 门禁补负样本**：现断言只查「存在性」（torus 在/发壳不在），必须补：micah/Jack→bald、open-peeps/Leo→afro、personas/Ivy→无胡子、personas/Zoe→glasses='dark'、Ivy 肤色 S<0.45、渲染回读肤色探针。三个反转案例永久进回归。

## 八、修订指令清单（按优先级；P0 = 不修不发）

**P0（提取器正确性——特征反转类，三项均已实证）**
1. `pixelClusters` 背景采样：角样本 <4 时 `bgc=null`，删除边缘中点回退（修 open-peeps/Leo 爆炸头→秃）。验收：Leo→afro，发色≈#1a1a1a。
